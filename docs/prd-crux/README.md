## Crux 产品概述

Crux 是面向团队的「渐进式 AI native」协作平台：保留团队现有的任务系统与协作流程（Jira / TAPD / 禅道 / 飞书 / 钉钉 / 企业微信均可接入同步），把其中一部分工作（如调研、编码、测试、文档更新）逐步交给平台上的 Agent 与小队执行；Agent 直接以任务为上下文工作，产出代码或报告回到任务里，由人验收。它不替代 Claude Code、Codex 等编码 Agent（Runtime），而是把它们纳入团队级的任务看板、执行、验收与自动化体系。

核心概念链路：**任务**（要做什么）→ **Agent**（如何工作）→ **Runtime**（实际执行的编码工具）→ **电脑**（Runtime 运行的机器）。
