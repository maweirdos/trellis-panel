# 产物库与空间交付设计

产物主流程是：选择成果类型 → 在会话中提出要求 → 生成实际文件或设计源 → 自动归集 → 打开成果工作台 → 继续修改 → 按需发布到空间。个人使用不要求连接团队服务、选定团队身份或先转换为受管创作。

设计稿以 [设计会话、画布与产物合同](design-canvas-workflow.md)为核心实施路径，覆盖内置设计规则、实际页面生成、画布页面框、DOM 组件选择、局部修改、原型导航和产物库重开。设计画布与普通自由白板分别建模。

## 对象与空间关系

遵循 [PRODUCT.md](../PRODUCT.md)、[roadmap](roadmap.md) 和 [F04/F18](product-flow-interaction-prd.md#f04-设计文档和原型成果的评审与采纳)，采用“个人成果工作台 + 空间交付”。

| 对象 | 职责与边界 |
| --- | --- |
| 产物 | 本人可重新打开和继续处理的实际成果，引用文件、设计包、画布或已有受管创作；本机可独立使用。 |
| 文件或设计源 | 内容权威；原文件、设计文件、页面、素材与依赖共同构成果实，预览不替代源。 |
| 私有会话 | 生成或修改成果的执行上下文；来源会话和后续工作会话分别记录，未知来源不猜测。 |
| 本机修订与候选 | 固定读取或编辑基线；未应用候选不覆盖现稿，文件变化不等于空间发布。 |
| 空间发布版本 | 显式提交到指定空间的固定正文和完整资源；复用 creations 发布、评审、权限、回执。 |
| 任务采用 | 对具体发布版及意见水位的固定引用；新版发布不自动更新引用，也不推进任务阶段。 |

个人索引读取本人本机会话、明确授权目录和已有个人内容，不依赖当前团队来源在线。既有远端个人创作保持原所属服务与身份；服务离线时标不可用，不隐式复制或迁移身份。

个人 owner 复用主进程已有 private-conversations 创建者推导。Crux 本机 owner 与此创建者不是同一身份，不能按名称或 ID 猜测合并；旧创作和白板须在原授权下建立可证明的链接，无法证明时保留原来源打开。个人索引不绕过旧对象的空间 ACL。

Work/Code 是工作视图，不授予权限，也不更改运行目录。两种视图使用同一个个人产物索引，可显式筛选工程。团队空间产物页只展示该空间授权的草稿和发布版；本机发现文件不混入团队列表。切换空间不分享本人会话。

## 页面与交互

### 产物库

采用用户截图的信息顺序：标题与说明 → 搜索/目录/排序/网格列表 → 新建类型 → 类型页签及数量 → 成果卡片或空状态。视觉使用设置页基线、共享字体、表面色、10px 圆角与三档密度。

- 新建入口：设计稿、文档、幻灯片、白板。表格、报告和图片可从类型筛选及扩展新建菜单进入。缺少执行适配时说明具体原因，不制造空成果。
- 默认全部目录，可选应用管理的 Work 目录或已授权工程。会话和目录是筛选维度，不要求先选会话再找成果。
- 卡片展示缩略图或类型图标、名称、格式、目录/来源、更新时间及简短状态。点击主面打开成果，来源会话是次级动作。
- 空库以新建为主动作；无搜索结果提供清除筛选。加载、目录部分失败、文件丢失和空库分别反馈。
- 回库保留搜索、筛选、排序、视图与滚动。刷新不关闭成果或清空未发送指令。
- 从任务或会话进入工作台时，返回原任务/会话的原成果位置；ReturnContext 保留原路由、来源、产物/修订、页签、位置和草稿引用。
- 页面不堆放会话扫描器、独立白板子库、底层服务诊断和发布表单。

### 新建与生成

新建类型产生明确的会话创建意图，预填类型指令。输入框显示输出类型和实际目录；用户补充后发送才运行。原有会话及需求助手草稿单独保留，不被预填覆盖。路由切换必须离开旧专用工作面，不能仅依靠全局事件向当前输入框塞文字。

Work 默认应用管理的持久目录；Code 使用明确选择的工程。生成期间展示真实执行与停止入口。未写出可识别成果时说明“本次尚未生成可打开的产物”，保留会话和输入；缺少格式生成能力时在发送前说明，不把普通文本改扩展名当作 Office。

实际文件写出并通过类型及读取校验后登记到索引，会话中出现成果卡片，库中出现同一产物。一次会话可生成多个产物，一个产物可有多个修改会话。手工空文档、导入和空白画布是独立动作，均进入同一个库。

### 成果工作台

顶栏显示“返回产物 / 名称 / 格式 / 保存状态”，右侧为导出、来源会话和发布到空间。内容占主区域，右侧助手可收起；来源、历史和交付放次级页签。窄窗口只保留内容和一个可切换侧栏。

| 类型 | 主工作面 | 持久内容与修改 |
| --- | --- | --- |
| 文档 | 阅读/编辑、目录与选区；DOCX/PDF 分页。 | MD/TXT 保存原格式；Office 的内嵌阅读、AI 修改、外部编辑分别表示。 |
| 设计稿/原型 | 页面与状态导航、多屏画布、所选页面预览、可切换交互预览。 | 设计描述、页面树、HTML/组件源和素材包一同保留；设计源和可点击原型分别导出。 |
| 幻灯片 | 缩略图栏、当前页、翻页、缩放和演示。 | 保留 PPTX 或支持的源，助手带当前页；只读预览不承诺拖拽编辑。 |
| 表格 | 工作表切换、网格、范围选择和统计。 | 保留 XLSX/CSV，助手带工作表/范围；区分公式、缓存值、重算与图表支持。 |
| 白板 | 自由画布、图形、文字、连线和导出，使用相同助手壳。 | 可编辑场景及素材；节点流程图作为子格式，不能代替自由白板。 |
| 报告 | 指标、图表、说明与数据依据。 | 结构化源和数据摘要；空图表不当作成果。 |
| 图片 | 缩放、适应窗口、信息与原文件导出。 | 保留原字节与明确的修改会话；阅读器不承诺图片编辑。 |

助手复用现有模型、执行引擎、停止和恢复能力，不新增 Agent 运行层。设计稿必须同时有可编辑源和可运行原型，不能用单张截图或单个无资源 HTML 代替。

设计稿入口内置设计规则并绑定明确文档与风格快照；画布选择元素后，输入框携带页面、元素路径、内容片段和源修订。普通打开、选区和预设动作准备不等于发送，用户发送后才生成修改。复用现有 Pi 的工具扩展、preview_web 和会话预览服务，补齐设计文档、画布和索引合同；不将普通网页预览标为已具备设计编辑器。

### 继续修改

打开成果不启动模型。来源可用时显示原会话，并允许切换“仅围绕此产物的新会话”。来源丢失或归档时保留成果阅读，明确创建新会话，不宣称恢复原执行身份。

回原会话单独校验原创建者、会话和执行目录；原文件缺失不应阻止进入仍然合法的会话。读取或修改文件则继续校验文件身份及修订，不用同名替代文件冒充原源稿。

发送时固定产物、实际目录、输入修订、选定页/范围和指令。按 F04，在候选副本或受控候选内容上修改；完成后展示变化及“采用修改 / 保留现稿”。采用时再次核对修订；文件变化则保留两份内容解决冲突。失败、取消、未写文件和没有实际变化分别反馈。

采用 Kun 的“阅读器 + 会话 + 自动刷新”布局；本项目继续保留候选确认门槛。外部应用主动保存时提示文件已更新，重新读取后保留阅读位置；不得覆盖待采用候选。

### 空间发布、评审与采用

个人编辑不要求选团队。点击发布后选择协作来源、空间和可选任务，预览所选版本、页面、素材与可见范围。发布生成固定快照和回执，只发送所选正文与必需资源，不上传私人会话、提示词和其他目录文件。

团队读者阅读固定版并提意见；有权编辑时从明确基线建立共享草稿或修改副本。任务采用仍固定具体发布版、意见水位和规则。共享草稿同步、发布、采用与阶段提交分别反馈；空间离线不阻断个人编辑。

已有 task-outputs 的明确任务文档纳管、daemon 同步和冲突处理继续复用。它只覆盖原绑定任务及约定材料，不扩成监听私人目录的第二套上传器。一个个人产物向多个空间交付时分别建立发布绑定，不迁移原 Creation 的空间或历史。创建目标草稿与发布分别保留原命令和回执，中断后恢复原目标。

设计交付包包含可编辑设计源、可运行原型、页面/状态清单、素材、token/组件映射。F18 的节点批注与实现对照依赖包结构，不能只存入现有 256 KiB 正文。

## 技术重构

### 统一索引和适配器

新增本机 ArtifactIndex，聚合授权来源，不复制全部文件。记录稳定 artifactId、类型、标题、所有者、sourceRef、当前修订、可用性、操作能力、来源会话与工作会话。sourceRef 由主进程授权定位文件、受管创作、设计包或画布，renderer 不任意传绝对路径。

各格式描述读取、预览、选区、候选编辑、保存和导出能力。库、会话成果卡片和工作台使用同一 artifactId 和适配器。已有 Creation 通过 ManagedCreationAdapter 接入；跨协作服务的同名对象不能当作同一来源。

自动归集来源：

1. 应用创建、导入和类型工具成功写出时，登记确切身份、原会话与修订。
2. 支持的引擎回合结束时，读取真实交付清单或核对预先明确的输出目标；文件未验证时不登记成功。
3. 外部工具和旧会话通过有限目录补扫进入“目录发现”；只有明确执行证据才显示“由会话生成”。发现项可直接打开，无须先转成受管草稿。

索引异步增量更新，缩略图按需生成；启动不扫描全部工程。库打开、已知写入、相关回合结束和用户刷新触发有界更新，部分失败仅影响该来源。保留既有路径授权、身份/修订校验、CAS、取消和恢复原操作机制。

## 实施顺序与验收
