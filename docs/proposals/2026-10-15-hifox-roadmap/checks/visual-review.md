# 文档与图表视觉复核

2026-10-16 UTC。范围仅为本轮研究交付物，不是 Trellis 产品或 Hifox 业务 UI 验收。

已在浏览器渲染 7 张 Mermaid 图，分别生成独立 SVG 与白底 PNG；打开核对全部 9 张图表（含 2 张可编辑 SVG 线框）。检查标题、中文字体、边界、标签、流向、分支、说明和可读性。核心 ER 为关系总览，完整字段和更多实体在数据字典，未宣称是物理数据库结构。

发现并修复：Mermaid 默认 HTML 标签使 SVG 状态图无法独立 XML 解析，改为纯 SVG 文字；PNG 透明底影响单独查看，改为白底；分层 DFD 长标签和状态图回边曾重叠，缩短标签并整理布局，完整语义留在正文状态与字典表。最终 SVG 均可独立 XML 解析，PNG 均成功输出，检查结果见 validation.json。

整合 HTML 在 Chrome 实际打开，抽查封面/证据限制、目录、数据模型和实体字典长表；确认没有页面级水平溢出，表格换行可读，9 张 SVG 已内嵌。目录原有平滑滚动导致长文跳转等待，改为立即跳转并核对目标位置。截图在 screenshots/。SVG 图表可单独打开缩放；HTML 不依赖远端脚本，Markdown、JSON、Mermaid 与 SVG 均保留编辑源。

限制：未制作 DOCX/PDF，托管文档运行时加载器在本委派执行环境返回不支持本地线程；没有使用未经技能允许的系统 DOCX 构建/渲染替代。交付格式为项目原生 Markdown、单文件可读 HTML、机读 JSON、Mermaid/SVG 编辑源及 PNG。未做全文逐页打印版式认证或无障碍合规认证。
