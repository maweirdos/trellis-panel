### P0-3 CLI 命令运行抽屉

不做完整终端页，做全局轻量抽屉 [02 P0-3]。

```
                                    ┌─ 命令运行器 ──────────── Alt+R / Esc ─┐
                                    │ < 输入命令… >            ( 运行 ) (·中止·) │
                                    │ 常用快选: [trellis scan] [trellis       │
                                    │   channel list] [tpanel --help]  历史 ▾  │
                                    ├──────────────────────────────────────────┤
                                    │ $ trellis channel list                   │
                                    │ dispatch   forum   3 成员                │
                                    │ worker-1   chat    implement   running   │
                                    │ worker-2   chat    check        idle     │
                                    │                                          │
                                    │ ┌ 退出码 0 · 08:32:11 · 耗时 1.8s ┐ 绿底  │
                                    └──────────────────────────────────────────┘
```

```
运行中状态（右上角固定条，出现在所有页面之上）:
┌─ ⚙ trellis channel worker-1 正在运行… 1.8s   (·中止·) ─┐
```

**解说**：从屏幕底部滑出的抽屉，任意页面 Alt+R 或命令面板动作唤出；命令输入框带历史（读 Settings 已有的 cliCommand 配置 [面板 三·1]）与常用命令快选；输出区实时滚动（消费现成的 `cli:output/done` 事件流 [面板 二·18]）；退出码回显是核心——它把「命令跑过没有」变成机器可读，P1-5 归档门直接依赖 [02 P0-3]。中止按钮只在运行中出现。Settings 页加一个「打开命令运行器」按钮即可。**热键裁定（评审补充）**：默认取 **Alt+R** 而非 Ctrl+R——Ctrl+R 是 Electron/Chromium 默认「重新加载窗口」加速键（平台通识，非本仓代码证据；本仓现有全局快捷键仅 Ctrl+K 与 Ctrl+.，`App.tsx:56-60`），占用需在主进程拦截 before-input-event 屏蔽默认刷新、得不偿失；Alt+R 与速记窗 Alt+N（`src/main/index.ts:281`）同族，无冲突。若实施时坚持 Ctrl+R，须连同拦截方案一起交付，不作为默认。

**空态**：抽屉首次打开无历史时，输出区显示一行灰字「还没有运行过命令。试试 trellis scan」，快选 chips 仍展示。

```
TitleBar 铃铛 ③ → 下拉面板:
┌─ 通知中心 ────────────────────────────────┐
│ ▓ 需要我动作 (3)   ▸ 摘要                  │
│ ┌ 09-28-药库… HONSKY-536 ───────────────┐ │
│ │ 等待输入 ×2 · 门禁失败 ×1 · 14:32       │ │
│ │ 代理问: 目标库是 oceanbase 还是备库?    │ │
│ │ ( 打开任务 ) ( 回一句 ) (· 稍后 ·)      │ │
│ └────────────────────────────────────────┘ │
│ ┌ 09-27-台账盘点校准 ────────────────────┐ │
│ │ 停滞超时 · 已 5h 无进展                  │ │
│ │ ( 打开任务 ) ( 重新派发 )               │ │
│ └────────────────────────────────────────┘ │
│ ── 已全部处理 ──                           │
│ 设置:                                      │
│ □ 等待输入   □ 门禁失败                    │
│ □ 卡住超时   □ 任务失败    → 弹 toast+角标  │
│ （AI progress 消息永不弹通知）              │
└────────────────────────────────────────────┘
摘要 tab:
┌─ 摘要 · 09-29 ─────────────────────────────┐
│ 完成 4 · 失败 1 · 新增 6 · 归档 2  ( 定时一份 )│
└────────────────────────────────────────────┘
系统 toast 形态（右上角）:
┌────────────────────────────────────┐
│ ⚠ 09-28-药库… 代理等待输入          │
│ 代理问: 目标库是 oceanbase 还是备库? │
│ ( 回一句 )  ( 打开 )  ×             │
└────────────────────────────────────┘
```

**解说**：只留两类通知：需要我动作（弹 toast + 托盘角标 + 进通知中心）与摘要（定时一份不弹）[OSS 6、02 P1-10]。按任务分组合并，同任务十条动态归一条；每条可就地处理（打开 / 回一句 / 重新派发），回一句在 toast 里直接展开输入框。「等我处理」队列（P0-1）与通知中心是同一份数据的两个视图——队列是拉、通知是推 [02 P1-10]。AI progress 消息永不产生 toast，这条写死在设置文案里（红线 [OSS 6]）。设置只做「这三类 + 其余进流」的开关，不做通知偏好矩阵。

**空态**：无通知时铃铛无角标，面板显示「✓ 没有需要你处理的事」，摘要 tab 始终有内容（当日零完成时显示「今天还没有完成记录」）。

## 四、空态与降级汇总

| 页面/区块 | 空态 | 一句话立场 |
| --- | --- | --- |
| 今日工作台·进行中 | 「没有代理在干活」+ 去派发台按钮 | 行动号召 |
| 今日工作台·等我处理 | 「✓ 清爽，没有等你处理的事」 | 正反馈 |
| 今日工作台·今天完成 | 「今天还没有完成的任务」+ 说明 | 说明性 |
| 命令运行抽屉 | 「还没有运行过命令。试试 trellis scan」 | 引导第一条命令 |
| Jira 同步中心 | 未连接 → 引导横幅去设置；未关联任务 → 同步列灰「—」 | 不硬闯 |
| 归档预检门 | 预检命令失败 → 提供跳过但记录 | 门失效不锁死归档 |
| 检查回执区块 | 无回执 → 说明 + 派发检查按钮 | 空是流程事实，不是错误 |
| 规范资产页 | 体检无问题 → 一行绿字；无 pending → 隐藏清账提醒 | 健康不啰嗦 |
| 规范资产页·无轨道结构 | 降级为按包平铺视图 + 「(· 迁移到轨道结构 ·)」引导（本仓现状即此态） | 通用工具不硬套参考结构 |
| 交付物区块 | 无声明 → 收起为一行 | 零打扰是设计要求 |
| 通知中心 | 「✓ 没有需要你处理的事」 | 正反馈 |
