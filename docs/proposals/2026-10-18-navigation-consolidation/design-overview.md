## A 入口顺序

```callout info 首页 / 智能体 / 任务 / 团队 / 知识
设置保留在底部。
首页以个人记录为主。
智能体放第二位，团队保持独立入口。
一级名称采用不同词根。
```

| 入口 | 主要对象 | 核心内容 |
| --- | --- | --- |
| 首页 | 个人记录 | 最近访问、阅读、对话与收藏 |
| 智能体 | Agent 与角色 | 对话、角色、频道及辅助问答 |
| 任务 | 项目事项 | 需求、任务、迭代、归档和项目工具 |
| 团队 | 人与协作 | 成员、分工、动态、统计与报告 |
| 知识 | 资料与规则 | 资料、规范、公司库 |
| 设置 | 配置 | 偏好、模型、引擎、集成与 MCP |

“工作台、工作、工作项”不再并列作为导航名称。
内部路由和会话标识仍可沿用。

## C 职责边界

| 场景 | 主要入口 | 关联方式 |
| --- | --- | --- |
| 创建需求、建任务、排自然周 | 任务 | 复用原有受控操作 |
| 调整任务负责人 | 同一份任务详情 | 团队可以打开这份详情 |
| 查看成员负载与任务摘要 | 团队 → 成员 | 查看全部时进入带负责人筛选的任务列表 |
| 查看协作变化与效率 | 团队 → 动态 / 统计 | 不复制任务管理和排期界面 |
| 查看代码变化、运行脚本 | 任务 → 工具 | 按当前项目使用，无需绑定某个任务 |

同一批任务可有事项视角和成员视角。
主操作、数据来源和修改路径保持一致。
首页仅呈现有实际来源的个人记录。
全项目文件更新不能直接改称“我的记录”。

## D 页面合并

| 当前内容 | 归属 | 合并方式 |
| --- | --- | --- |
| 工作项＋迭代 | 任务 | 同一集合与详情，切换排期视图 |
| 团队＋统计 | 团队 | 统计集中；报告单独呈现 |
| 知识＋规范 | 知识 | 统一来源浏览与阅读 |
| Agent＋频道＋通用问答 | 智能体 | 复用控制器，保留类型与范围 |
| Git＋运行日志＋架构＋定制 | 任务 → 工具 | 内容区切换，保留现有能力 |

统计保留时间、来源和归档口径。
成员记录不被标记为在线身份。
模型问答是辅助工具，不等同于执行型 Agent。

## E 名称选择

| 原名称 | 建议名称 | 处理方式 |
| --- | --- | --- |
| AI 工作台 | 智能体 | 聚焦当前 Agent 核心能力 |
| 工作 | 任务 | 明确项目事项管理 |
| 工作项 | 全部 | 在任务上下文中使用 |
| 本周计划 | 迭代 | 内容区选择自然周 |
| 保存的视图与收藏 | 视图 / 收藏 | 两个对象分开显示 |
| 成员与分工 | 成员 | 在成员页呈现分工与负载 |
| 统计与报告 | 统计 / 报告 | 指标分析与叙述报告分开 |
| 模型与执行引擎 | 模型 / 引擎 | 按配置对象分开 |

固定标题规则：一级2–3字，二级2–4字。
MCP、Git等必要缩写保留。
一个名称表达一个对象。
子项不重复父级已经说明的范围。
真实任务名与文档名保留内容，长标题可截断。

## F 使用方式

首页、智能体、任务、团队、知识按此顺序排列。
启动时优先恢复上次工作区的有效定位。
恢复页面不自动发送或增加执行授权。
现有会话与阅读器的生命周期保持不变。

二级导航只列本模块内容。
跨模块关联用明确动作表达。
任务预览保留来源位置。
旧称作为搜索别名继续可用。

## G 后续扩展

| Roadmap 方向 | 稳定位置 | 保留的边界 |
| --- | --- | --- |
| Agent 使用与阅读 | 智能体、知识与任务资料 | 沿用运行层和阅读器 |
| 粗需求与旧任务接续 | 任务 → 接入 / 任务详情 | 不新增重复台账 |
| Git、运行与日志 | 任务 → 工具 | 保留本机与进程归属 |
| 检查与交接 | 任务详情＋团队报告 | 区分检查与业务确认 |
| 项目成员与协作深化 | 团队 | 按真实共享能力扩展 |
| 外部来源 | 设置 → 集成；任务 → 接入 | 不按厂商增加一级图标 |
