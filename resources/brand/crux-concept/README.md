# Crux logo concept

This concept keeps Trellis Panel's restrained neutral language and introduces a four-arm point mark: the arms converge on a clear center to represent the crux of a decision, task, or workflow.

- `crux-mark.svg`: source glyph using `currentColor`.
- `crux-lockup.svg`: horizontal glyph and wordmark.
- `crux-favicon.svg`: 40 × 40 dark application tile.
- `crux-mark-*.png`: transparent glyph exports.
- `crux-icon-*.png` and `crux.ico`: dark tile exports for application surfaces.
- `crux-preview.png`: light/dark presentation sheet.

The files are concept assets only. They are not wired into the current Trellis Panel runtime.
