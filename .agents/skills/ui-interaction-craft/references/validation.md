# 交互验收

## 公共检查

| 检查 | 通过条件 |
| --- | --- |
| 按压与反馈 | 立即响应，无重复叠加，等待/成功/失败切换不推挤相邻控件 |
| 反复与反向操作 | 以最新选择为准，动效可中断，不排队播放过期状态 |
| 结果真实性 | 完成取实际结果，进度取完成量，取消与调用失败分别处理 |
| 异步归属 | 响应逆序、重试、恢复和跨窗口更新不覆盖有效新状态 |
| 阅读位置 | 上翻停止跟随，新内容和计数不改变外层工作区几何 |
| 文字与布局 | 长内容、数字换位、主题、大字号和语言变化不溢出或抖动 |
| 退出与恢复 | 取消、返回和关闭保留必要草稿，重新进入可恢复真实状态 |
| 可访问性 | 名称、焦点、读取顺序、命中范围和非颜色反馈完整 |
| 动效与资源 | 减少动效可用；隐藏、取消或卸载后无无意义循环和失效回调 |

## 按运行环境检查

| 环境 | 必测过程 |
| --- | --- |
| 桌面应用 | 鼠标、触控板、键盘、IME、窗口缩放、DPI、焦点返回、分栏越界与 Escape 取消 |
| 桌面网页 | Tab / Shift+Tab、Escape、浏览器缩放、历史返回、滚动槽位、视口边缘定位 |
| 移动网页 | 真实触控、软键盘、地址栏伸缩、横屏、安全区、浏览器返回、长按与文本选择 |
| iOS App | 系统模态呈现、取消与交互式关闭、大字号、VoiceOver、键盘和外接输入 |
| Android App | Back / Predictive Back 的完成与取消、输入法、TalkBack、窗口模式与触控目标 |
| 小程序 | 宿主确认/取消/失败字段、页面生命周期、客户端差异、原生组件覆盖与真机键盘 |
| 混合容器 | Web 与宿主只消费一次返回/确认/权限事件，不重复显示加载或结果提示 |

仅验证实际交付平台。多端交付分别记录运行环境、系统/宿主版本和证据；浏览器截图、设备模拟或类型检查不能代替真机行为验证。

## 必测异常

- 在动效尚未结束时反向操作、关闭或取消。
- 慢请求后快速切换目标，让旧响应晚于新响应返回。
- 重要确认沿目标平台支持的取消、Escape、系统返回或外点路径退出，确认操作未被误执行。
- 返回手势开始后取消，检查页面、草稿和弹层状态未被提前提交。
- 正文增长、骨架交接、软键盘出现及计数变长时，检查内容、可见锚点与外层矩形。
- 组件离开后让后台结果返回，确认没有更新失效界面或伪造已取消状态。

## 方法

- 使用目标运行环境检查实际组件和连续过程；静态截图只验证静态布局。
- DOM 可配合浏览器检查矩形、焦点与动画；原生使用平台检查工具，小程序使用目标宿主开发工具和真机。
- 覆盖目标平台的减少动态效果与适当辅助技术，不依赖完全相同的 DOM 属性或测试工具。
- 按改动风险选择验证。低影响文案或局部样式调整不增加镜像测试或无关的整套构建。
