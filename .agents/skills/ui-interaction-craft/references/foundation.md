# 通用交互规则

## 设计系统与输入

- 颜色、字号、间距、控件尺寸、圆角、层级和动效值使用项目令牌；原生系统控件保持系统行为。
- 没有现成设计系统时，使用目标平台默认控件和最小必要样式，不先更换技术栈或安装另一套组件库。
- 分开识别运行环境、输入方式与可用空间。鼠标、键盘、触控、手写笔可同时存在，不能用一个屏幕断点代替全部判断。
- 视觉尺寸与命中区域分别检查。紧凑图标可扩大有效命中区域，但不得与相邻控件的操作范围冲突。
- Web 使用 CSS 像素，原生使用平台逻辑单位，小程序按宿主布局单位与实际换算检查；不把 `px`、`pt`、`dp`、`rpx` 当成相同单位。
- 标签、关键说明、选中状态和恢复入口可直接发现；颜色、悬停、长按或动效均不能作为唯一信息来源。

## 真实状态

- 真实业务状态、等待反馈和成功反馈分别建模。请求被受理、提示框显示成功或动画结束，都不等于业务完成。
- 进度取实际完成单元；总量未知时只表达活动，不按经过时间编造百分比。
- 复制成功取实际复制结果，权限操作取明确决定与真实授权结果。
- 最新用户选择拥有当前画面。旧请求返回、页面恢复或跨窗口同步不得覆盖较新的有效状态。
- 失败保留输入、已有可用结果和恢复入口。未知结果不能表现为空数据。
- 取消、关闭界面和取消后台任务分别处理；不支持中止的任务仍需防止迟到结果更新已离开的视图。

## 反馈节奏

- 按下即可见反馈；等待、成功、失败切换时预留控件和图标尺寸，相邻内容不移动。
- 自绘按压可轻微缩放或改变表面状态；系统控件已有反馈时沿用其机制，不额外叠加缩放、涟漪或震动。
- 轻弹用于短促成功图标，结构性浮层不反复过冲。键盘高频选择即时定位。
- 自绘短成功表现默认约 `2.5s` 后退去；系统提示遵循宿主时限及可访问设置，不为统一时长重复显示多层提示。
- 点赞选中、收藏或保存结果属于持久业务状态，不能随临时对勾一起消失。
- 消息操作栏在鼠标悬停或键盘进入时轻显；触控环境常显或提供直接可发现入口，区域预留，不推挤正文。
- 需处理的错误和重要决定保持可发现，不套用成功提示的短时限。

## 状态与焦点同步

- 展开图标、按钮强调态、可访问状态与内容开闭由同一状态驱动，关闭后一起归位。
- 隐藏的内容和控件不可继续被激活或被辅助技术误认为仍可操作。
- 模态任务实际隔离背景；非模态界面不阻止用户访问仍可用的主任务。
- 初始焦点、默认按钮、取消角色与按钮排列分别处理；系统对话框按平台语义设置，不能把网页焦点规则直接转换为原生默认按钮。
- 关闭后把键盘或辅助技术焦点放回合理位置；原触发点已不存在时选择流程中的下一处有效目标。

## 生命周期与连续性

- 动效可中断，快速反向操作从当前进度接续，不排队重播。
- 取消、替换、离开、后台或卸载时停止无意义的局部活动；恢复后依据真实任务状态展示。
- 动画完成事件不充当业务就绪条件，不为完整播放动效强制延迟下一次操作。
- 减少动态效果时降低位移、模糊和回弹，内容和操作仍完整可用。
- 实际读取顺序、焦点顺序与主要视觉层级一致，不逐字、逐帧或因重复设置相同文本反复播报。

## 表单与正文

- 校验在提交或字段已触碰后进行，错误靠近字段，原输入保留；需要时定位首个错误。
- 中文组字期间的 Enter 用于确认候选，不触发提交；同时核对组合输入、换行、软键盘动作和外接键盘。
- 长文本、长链接、代码、emoji、大字号和多语言均可阅读和复制，不用手工换行破坏原内容。
- 暗色字重按字体实际效果校准，不机械减去固定数值，不通过降低整体透明度损失正文对比。
