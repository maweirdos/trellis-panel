# 动效与阅读

## 动效基准

以下数值用于支持相应效果的自绘界面；原生系统控件沿用系统动效。接入项目动效令牌后，根据内容面积、输入频率和性能调整。

| 场景 | 表现 | 基准 |
| --- | --- | --- |
| 新字出现 | 少量新字由模糊和透明渐清晰，邻字过渡重叠 | 模糊 `6px → 0`，约 `120ms`，相邻约 `30ms`，`cubic-bezier(.16,1,.3,1)` |
| 分栏吸附 | 拖动直接跟手，松手短促落位 | 吸附约 `150ms`，无反复摆动 |
| 轻量 Popover | 从触发处轻移淡入，箭头与强调态同步 | 位移约 `2px`，约 `140ms`，无按钮本体缩放回弹 |
| 自绘模态任务 | 短促进入，单向退场 | 进入位移约 `6px`，退出约 `110ms` |
| 等待首段回复 | 气泡内三点依次轻跳 | 位移约 `4px`，周期约 `900ms`，邻点相隔约 `120ms` |
| 成功反馈 | 图标轻弹、对勾短留 | 临时表现约 `2.5s`；持久业务状态保留 |

`px` 数值只对应 Web 渲染。原生或小程序保持相同交互意图，使用平台单位与组件能力校准，不逐项照抄像素值。

## 流式文字

- 只让活跃的新内容参与渐清晰，已呈现正文保持稳定；避免整段反复模糊。
- 按实际到达批次呈现，正确处理组合字符、中文和 emoji，不为固定打字节奏无限积压内容。
- 少量到达字符可错开过渡；大批内容及时接入，不排长动画队列。
- 不用独立块布局拆碎字形、英文单词或行内选择。复制和辅助技术仍获得完整文本。
- 稳定、取消或替换后释放逐字节点和活动；减少动态效果时直接显示清晰内容。
- 渲染层不能低成本支持局部模糊时，改用小范围透明度接入；不通过整篇模糊或持续数据更新模拟效果。

## 计时器与排版

| 行为 | Web | 原生 App / 桌面原生 | 小程序 |
| --- | --- | --- | --- |
| 数字等宽 | `font-variant-numeric: tabular-nums`，必要时固定字符槽位 | 平台等宽数字字形与布局约束 | 核对字体与 WXSS 等能力，必要时使用等宽回退及字符槽位 |
| 自适应展开 | 支持时使用 Grid `0fr → 1fr`，内层 `min-height: 0; overflow: hidden` | 自动布局、内容驱动尺寸与平台展开动画 | 已有折叠组件或宿主支持的布局动画；能力不足时保留清楚的状态切换 |
| 段尾优化 | 支持时采用 `text-wrap: pretty`，独立处理长链接和代码 | 使用平台文本排版、断行和动态字号能力 | 使用运行层支持的排版与溢出策略 |
| 字重补偿 | 可变字体可从浅色 `450` / 暗色 `400` 起调 | 保留动态字号与系统语义字体，按实际字库校准 | 核对可用字重、字体加载与宿主渲染 |

- 为计时最长格式预留空间，数字、单位和分隔符变化不挤动相邻内容。
- 字库不支持连续字重时使用真实可用档位；等宽数字声明必须由实际字形或槽位保证。
- 浏览器展开由状态驱动，不测写思考框高度；其他运行层使用对应自动布局，避免每帧测量高度。
- 排版能力不足时验证中文段尾、标点及中英混排，不强行插入换行或修改复制内容。

## 阅读与滚动

- 位于底部时跟随新内容；用户上翻或明确停止跟随后保留阅读位置。
- 返回入口、状态栏和计数预留稳定空间，显隐与文字变化不改变外层工作区几何。
- 一个阅读区由一个滚动容器负责；原生锚定和自定义补偿不能重复移动同一内容。
- 浏览器滚动更新合并到必要的渲染批次；原生使用列表可见位置与尺寸回调，小程序合并数据更新。
- 不因每个字符到达就重复启动一段平滑滚动，不与触控惯性、滚轮或用户手势争抢位置。
- 图片、代码高亮或折叠区改变尺寸时，按是否跟读和实际可见锚点保持位置。
- 显式回到最新后再恢复跟随；软键盘、安全区或方向改变不应把用户从历史阅读位置强制拉走。

## 加载与刷新

- 三点等待放在回复气泡中，首段到达立即退出，不等待一轮跳动结束。
- 进度未知用局部活动状态；进度已知用真实完成量。API 调用成功不等于任务完成。
- 首次加载用匹配内容几何的骨架；微光只覆盖小面积、低对比区域，并随状态停止。
- 同一上下文刷新保留可用旧结果并标注更新；上下文不兼容时不得把旧结果伪装为新结果。
- 最新选择拥有画面，响应逆序、页面恢复和重复重试不能覆盖有效新结果。
- 原生或宿主组件无法按网页方式微光、逐字或叠加图标时，保留结构和真实状态，使用能力范围内的轻量反馈。

## 拖拽与排序

- 鼠标或触控移动时直接跟手；只有松手归位和邻项让位使用短过渡。
- 排序保留落点占位，提供按钮或键盘等价操作。
- 桌面分栏处理指针捕获、移出区域、Escape 与取消，恢复拖动前基准值。
- 触屏拖拽使用清楚的手柄，区分滚动和拖拽；仅在必要区域抑制默认手势。
- 不覆盖系统边缘返回、文本选择或平台保留手势；取消手势不能错误提交排序或导航。
