# 反馈与弹层

## 选择反馈

先判断信息范围、任务复杂度、是否需要决定，再选择平台容器。只有模态任务隔离背景；普通状态不因视觉突出就阻断用户。

| 场景 | 桌面应用 / 鼠标网页 | 移动网页 | 原生 App | 小程序 |
| --- | --- | --- | --- | --- |
| 字段错误 | 字段旁说明，提交时定位首个错误 | 同样就地说明，焦点与软键盘不遮挡 | 原生字段错误与辅助技术描述 | 表单附近错误，按宿主输入与播报能力关联 |
| 单次请求失败 | 任务旁 Alert，保留输入与重试 | 任务旁持久警示，动作容易触达 | 内容内错误和重试，避免普通失败反复弹系统警告 | 内容内错误与重试，不只给短 Toast |
| 整体离线或降级 | 工作区持续横幅 | 页面横幅或稳定状态区 | 页面状态区，仍可用内容继续操作 | 页面状态区，恢复不清空草稿 |
| 短成功结果 | 就地对勾或 Toast | 轻提示，不遮挡键盘和主操作 | 沿用系统或现有组件 | 宿主 Toast 或已有组件，服从能力限制 |
| 图标补充说明 | Tooltip 支持 hover 与键盘 | 可见标签或可点击说明入口 | 原生帮助方式与明确名称，支持辅助技术 | 可见名称或直接说明入口 |
| 少量就近选项 | 锚定 Popover 或菜单 | 触控 Popover、选择页或底部选择面板 | 系统菜单、动作菜单或合适的选择界面 | 宿主 ActionSheet 或已有选择组件 |
| 完整设置表单 | 范围明确的 Modal 或独立页面 | 优先独立页面；较短任务可用适配后的模态界面 | 导航页面或系统上下文模态呈现 | 独立页面，避免将复杂表单塞入宿主提示框 |
| 必须确认的重要动作 | 明确范围的确认对话框 | 可触达的确认，取消不丢草稿 | 系统确认角色与平台默认行为 | 宿主确认能力，检查明确选择结果 |
| 未保存离开 | 保留草稿，必要时提供保存、放弃、继续编辑 | 不完全依赖浏览器离开提醒，先保留草稿 | 随系统返回与交互式关闭处理选择 | 页面生命周期先保存草稿，支持时使用宿主离开提醒 |

底部选择面板用于少量动作和选项；复杂阅读、详情或多步编辑采用内容页面或合适的完整任务容器。

## 就地警示与短结果

- 错误靠近受影响字段或任务，不抢夺无关焦点；保留输入、可用旧结果、重试和按需详情。
- 重要警示与需处理的失败不按短成功提示的时限自动消失。
- 连续成功更新同条反馈，不堆叠占满画面；可交互提示在用户停留时不得突然消失。
- 系统 Toast 无法承载重试时，恢复动作放入持久内容，不把网页自绘按钮套进系统 Toast。
- 权限、重要限制及风险在决定前直接可见，不能只藏在 Tooltip、短 Toast 或离开的手势里。

## Tooltip、Popover 与菜单

- Tooltip 承载短说明；有按钮、输入或选项时使用交互式容器。
- 鼠标的首个 Tooltip 略等，同组连续探索免去反复等待；键盘焦点可见，Escape 与激活能关闭。
- 触控不依赖 hover；长按只作平台允许的补充，必要说明提供可见或直接点击入口。
- 展开图标、强调态与真实开闭一致。锚定容器在空间不足时调整位置，触发点离开可见区域时按任务语义关闭或转到稳定容器。
- 菜单选择后执行并收起；键盘导航、焦点返回和外点规则由对应组件实现。
- 系统菜单和动作菜单保留默认取消、按钮角色和系统定位，不额外套一层网页关闭逻辑。

## 模态与重要确认

- 使用明确标题、相关动作与取消出口，不为普通通知反复创建模态任务。
- 背景真实不可操作才能声明模态；DOM 使用相应语义，原生和小程序使用平台可访问性与组件机制。
- 初始焦点、默认按钮和按钮顺序服从平台约定与风险。自绘桌面重要确认可将初始焦点放在安全操作，不能把这一做法机械转换为原生系统默认按钮。
- 取消、Escape、返回或允许的外点关闭只能产生取消语义，不能推断为确认；对风险操作只接受明确的肯定选择。
- 未提交内容在取消或关闭时保留；放弃数据必须对应清楚动作。系统允许的交互式关闭与未保存保护一并处理。
- 不超时自动同意；同一状态最多执行一次确认，快速点击和多入口不会重复提交。
- 一次关闭只处理最上层有效临时界面；输入法、系统弹层和页面导航由实际拥有者处理。

## 命名与语义

Web 的 Inline Alert 是不抢焦点的重要消息；Apple 系统 Alert 通常是模态呈现，名称不能直接决定交互行为。Toast 与 Snackbar 按短通知职责处理，具体能力取决于组件与宿主。选择时检查背景可交互性、用户需要完成的任务和退出路径。
