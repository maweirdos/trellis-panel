# PRD — 全新外壳 UI 体系（双栏导航、多布局工作项与主题系统）

## Goal

在 trellis-panel 渲染层新增一个自包含的 **参考 UI 克隆模块**，完整复刻
参考仓库（上游令牌包 设计系统一代）的应用外壳、导航结构与全部主要界面的视觉与交互；
内容使用自拟演示数据（中文项目/工作项），不复制 参考 的品牌、业务内容与代码
（仅提取其开源仓库公开的设计令牌值与 SVG 图形路径）。

## Requirements

- R1 应用外壳：双侧边栏（工作区侧边栏 + 项目侧边栏）+ 主内容区 + 顶栏；
  工作区切换器、搜索入口（Ctrl+K 提示）、Your work / Inbox / Analytics 导航、
  收藏与全部项目列表、底部用户菜单；项目侧边栏含 Work items / Cycles / Modules /
  Views / Pages / Intake 六项。
- R2 工作项页：5 种布局可切换——List（按状态分组可折叠行）、Board（看板）、
  Spreadsheet（密集表格）、Gantt（时间条）、Calendar（月历）；分组（状态/优先级/负责人）、
  排序、筛选（优先级/状态/标签/负责人）、显示选项；新建工作项弹窗；点击行弹出
  peek-over 详情浮层（标题/描述/右侧属性列/子工作项/活动）。
- R3 周期页：全部/活跃/即将到来/已完成分页签，周期卡片（日期区间、进度条、成员、
  工作项计数）；活跃周期详情（倒计时、进度、工作项看板）。
- R4 模块页：模块卡片网格 + 详情（进度、负责人、成员、工作项看板）。
- R5 视图页：已存视图卡片 + 详情（筛选后的工作项看板）。
- R6 页面（Pages）：左侧文档列表 + 右侧编辑器（emoji 图标、标题、正文可编辑）。
- R7 接收（Intake）：待接收工单卡片，接受/拒绝/重复/挂起状态操作。
- R8 Your work：问候语头 + 已分配/由我创建/近期工作项小组件。
- R9 分析页：指标卡 + SVG 图表（创建/关闭柱状、状态分布、优先级分布、成员排行）。
- R10 项目页：全部项目卡片网格 + 新建项目弹窗。
- R11 设置：项目设置（常规/状态/标签/成员/功能）、工作区设置（常规/成员）、
  偏好外观（浅/深/高对比主题卡 + 自定义主题：强调色/字体）。
- R12 命令面板：Ctrl+K，分区导航/项目/主题，键盘上下选择，可执行跳转与切主题。
- R13 主题：`data-my-theme` 令牌化浅/深主题，跟随面板设置初始化，模块内可切换并持久化。
- R14 交互质感：下拉菜单/工具提示/头像堆叠/空状态/滚动条样式与 参考 交互模式一致。
- R15 集成：作为面板一级页面（Sidebar 入口「参考 UI」）按需加载；不触碰既有页面与 IPC。

## 约束

- 不复刻登录/注册、计费、API Token 等后台页；不接真实后端，数据为内存 mock；
  仅主题/UI 偏好持久化（localStorage，键前缀 `tpanel.my.`）。
- 遵守 `.trellis/spec/frontend/`：TS strict、无 `!` 断言、`JSX.Element` 返回类型、
  相对导入、不用 prompt/alert/confirm、可滚动容器 scrollbar-gutter。
- 不修改既有 `store/slices`（仅 Page 联合类型加 `'my'`），参考 模块内自治 store。

## Acceptance Criteria

- AC1 `npm run typecheck` 与 `npm run build` 通过。
- AC2 面板侧边栏出现「参考 UI」入口，进入完整 参考 外壳，退出返回原页面互不污染。
- AC3 工作项页 5 种布局均可切换渲染同一份演示数据；分组/排序/筛选/显示选项下拉可用。
- AC4 peek-over 详情可从列表/看板/表格/日历打开，属性列渲染完整。
- AC5 周期/模块/视图/接收/Your work/分析/项目/页面 全部界面可达且渲染演示数据。
- AC6 设置三组界面可达；主题卡与自定义主题可切换且刷新后保持。
- AC7 Ctrl+K 命令面板可搜索、键盘导航、执行跳转与主题切换。
- AC8 Electron 截图验证：深浅两套主题下外壳与工作项页与 参考 视觉一致
  （画布/分层底色、品牌蓝、状态图标形状、布局切换器、列表行结构）。

## 演示内容（自拟，非 参考 内容）

工作区「星港工坊」；项目：网站改版、移动端 App、数据平台；工作项 40+ 条中文标题，
含优先级/标签/负责人/周期/模块分布；成员 5 人。
